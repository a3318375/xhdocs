在我追问下，ai给出了如下方案

自定义分片算法（Class Based）

```java
// 你的自定义路由逻辑
public String doSharding(Collection<String> availableTargetNames, PreciseShardingValue<Long> shardingValue) {
    long id = shardingValue.getValue();
    // 假设你从起始ID开始，每 50万 个 ID 换一张表
    // 或者更简单的：(id - 起始ID) / 500000
    long tableIndex = (id - START_ID) / 500000; 
    return "resource_" + tableIndex;
}

```
